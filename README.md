核心功能
实时行情监控： 实时观察 BTC 价格变。
事件合约分析： 针对短周期 BTC 事件合约的交易场景，提供专门的分析与监控功能。
信号状态监控： 实时查看系统生成的信号、触发时间和当前状态。
交易结果统计： 记录历史交易结果，统计命中率、盈亏表现和历史回撤。
专业监控界面： 将行情、信号状态和统计数据集中展示，方便用户持续观察市场变化。
Image
产品定位
这不是一个K 线查看工具，而是一款围绕 BTC 短周期事件合约使用场景设计的专业监控与自动下单的项目。

产品采用独立的策略计算与信号服务架构，重点关注实时性、数据记录、结果追踪和使用体验。
